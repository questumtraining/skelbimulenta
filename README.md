# Questum Training — vietinė versija

Šis aplankas paruoštas paleisti „Questum Training“ skelbimų lentą šiame Windows kompiuteryje.

## Paleidimas

1. Įdiekite Python 3.10 arba naujesnę versiją, jei jos dar nėra.
2. Dukart spustelėkite **Paleisti.vbs**, kad paleistumėte programą be komandų lango.
3. Pirmą kartą paleidžiant programa įdiegs reikalingą biblioteką. Tam reikės interneto ryšio.
4. Naršyklėje atidarykite **http://127.0.0.1:8000** ir susikurkite administratoriaus paskyrą.

Norėdami pamatyti paleidimo pranešimus, dukart spustelėkite **Paleisti.bat**. Programą sustabdysite paleidę **Sustabdyti.vbs**.

## Duomenys

Paskyros, grupės, skelbimai ir vertinimai saugomi aplanke `data`. Šiame pakete senos duomenų bazės nėra — ji susikurs automatiškai pirmo paleidimo metu.

Tai vietinė versija, pagal numatytuosius nustatymus pasiekiama tik iš šio kompiuterio. El. laiškų siuntimas neveiks, kol nebus sukonfigūruotas SMTP.
